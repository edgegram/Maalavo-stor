MAALAVO STORE
ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ

Дата редакции: 20 сентября 2026 года

1. ОБЩИЕ ПОЛОЖЕНИЯ
1.1. Настоящая политика описывает обработку данных при использовании Maalavo Store.
1.2. Политика применяется к данным, которые пользователь предоставляет непосредственно или которые технически создаются при использовании магазина.

2. КАКИЕ ДАННЫЕ МОГУТ ОБРАБАТЫВАТЬСЯ
2.1. Данные профиля: имя/никнейм, аватар и иная информация, которую пользователь самостоятельно указывает.
2.2. Данные заказа: выбранные товары, сведения о заказе и переписка по его выполнению.
2.3. Технические данные могут включать сведения, необходимые для работы сайта и сохранения пользовательских настроек.

3. ПРОФИЛЬ
3.1. При наличии профиля данные профиля используются для отображения и работы соответствующих функций.
3.2. Пользователь самостоятельно определяет, какую дополнительную информацию размещать в профиле.

4. КОРЗИНА
4.1. Сведения о товарах в корзине могут сохраняться локально на устройстве.
4.2. Эти данные используются для работы корзины и оформления заказа.

5. ИЗБРАННОЕ
5.1. Список избранных товаров может храниться локально.
5.2. Избранное используется для удобства пользователя.

6. ЗАКАЗЫ
6.1. Информация о заказе используется для его обработки и связи с пользователем.
6.2. Данные могут сохраняться в объеме, необходимом для исполнения заказа и разрешения спорных ситуаций.

7. TELEGRAM
7.1. При обращении через Telegram пользователь взаимодействует со сторонней платформой Telegram.
7.2. Обработка данных Telegram регулируется также правилами и политикой конфиденциальности Telegram.

8. ВНЕШНИЕ СЕРВИСЫ
8.1. Maalavo Store может использовать внешние сервисы для хостинга, аналитики, связи, доставки цифровых товаров и других технических задач.
8.2. Такие сервисы могут обрабатывать технические данные в соответствии со своими правилами.

9. ЛОКАЛЬНОЕ ХРАНЕНИЕ
9.1. Часть функций может работать без серверной базы данных за счет localStorage, cookies или иных механизмов хранения в браузере.
9.2. Такие данные находятся на устройстве пользователя и могут быть удалены при очистке данных браузера.

10. ЦЕЛИ ОБРАБОТКИ
10.1. Обработка данных может осуществляться для работы магазина.
10.2. Для оформления и выполнения заказов.
10.3. Для связи с пользователем.
10.4. Для обеспечения безопасности и предотвращения злоупотреблений.
10.5. Для улучшения интерфейса и функциональности.

11. ПРАВОВЫЕ ОСНОВАНИЯ
11.1. Обработка осуществляется на основании согласия пользователя, необходимости исполнения запроса или иных применимых правовых оснований.
11.2. Конкретное основание зависит от характера данных и выполняемой операции.

12. ПЕРЕДАЧА ДАННЫХ
12.1. Данные не должны передаваться третьим лицам без соответствующего основания.
12.2. Передача может осуществляться техническим подрядчикам или сервисам, когда это необходимо для работы магазина или исполнения заказа.

13. БЕЗОПАСНОСТЬ
13.1. Принимаются разумные технические и организационные меры для защиты данных.
13.2. Ни один способ хранения или передачи данных через интернет не может гарантировать абсолютную безопасность.

14. СРОК ХРАНЕНИЯ
14.1. Данные хранятся столько, сколько необходимо для соответствующей цели, исполнения обязательств или соблюдения требований законодательства.
14.2. Локальные данные могут существовать до их удаления пользователем или браузером.

15. УДАЛЕНИЕ ДАННЫХ
15.1. Пользователь может удалить доступные ему локальные данные через настройки браузера или соответствующие функции магазина.
15.2. Для данных, которые находятся у Maalavo или технического подрядчика, запрос может быть направлен через контактный канал.

16. ПРАВА ПОЛЬЗОВАТЕЛЯ
16.1. В зависимости от применимого законодательства пользователь может иметь право на доступ, исправление, удаление, ограничение обработки или иные права в отношении своих данных.
16.2. Запросы рассматриваются с учетом требований законодательства и возможности подтвердить личность заявителя.

17. ДЕТИ
17.1. Пользователь должен соблюдать возрастные ограничения, установленные применимым законодательством и условиями соответствующего сервиса.
17.2. Если законодательство требует согласия законного представителя, оно должно быть получено.

18. ИЗМЕНЕНИЯ ПОЛИТИКИ
18.1. Политика может периодически обновляться.
18.2. Актуальная редакция публикуется вместе с указанием даты обновления.

19. КОНТАКТЫ
19.1. По вопросам обработки данных пользователь может обратиться через официальный контакт Maalavo.
19.2. Основной контакт: Telegram — @maalavo.

20. ЗАКЛЮЧИТЕЛЬНЫЕ ПОЛОЖЕНИЯ
20.1. Политика действует в отношении обработки данных при использовании Maalavo Store.
20.2. Если отдельное положение становится неприменимым, остальные положения сохраняют силу.
20.3. Использование сервиса после обновления политики означает ознакомление с ее новой редакцией в той мере, в какой это допускается применимым законодательством.

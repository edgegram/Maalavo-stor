# Maalavo Store Admin

Отдельный интерфейс администрирования. Использует существующий backend API.

По умолчанию API: `/api`. Для отдельного Railway backend перед `admin/js/admin.js` можно задать `window.MAALAVO_ADMIN_API_URL`.

Возможности: вход администратора, статистика, заказы и смена статусов, создание/редактирование/скрытие товаров.
